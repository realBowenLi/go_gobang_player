# 棋类对战平台（阶段二）

支持五子棋、围棋、黑白棋，支持本地双人、人机、AI vs AI，对局录像/回放与账号战绩管理。

## 运行

- 依赖：Python 3.7+，tkinter（标准库）。
- 控制台：`python main.py`
- GUI：`python main_gui.py`

## 控制台命令速览

- `start <type> <size> human` — 本地双人
- `start <type> <size> ai <black|white> [aiLv]` — 人机（AI Lv1 随机 / Lv2 邻近）
- `start <type> <size> aivsai [ai1Lv] [ai2Lv]` — AI 对 AI
- `place <row> <col>` 落子；`pass` 虚着/跳过（围棋、黑白棋）；`undo` 悔棋；`resign` 认负
- `save <file>` / `load <file>` — 保存/读档（含录像）；`replay <file>` — 文本回放
- 账号：`register <user> <pwd>`，`login <black|white> <user> <pwd>`（登录后自动记胜场/总场次）
- 其他：`restart` 重新开始；`hint` 显示/隐藏提示；`quit` 退出

## 主要功能

- **游戏类型**：五子棋、围棋、黑白棋（默认 8x8，必须偶数）。
- **对战模式**：双人 / 人机 / AI vs AI；支持选择 AI 等级。
- **AI 等级**：Lv1 随机合法落子；Lv2 优先贴近对手上一手，否则随机。
- **规则实现**：
  - 五子棋：连五胜、满盘平局。
  - 围棋：提子、打劫简检、自杀检查、虚着，双虚着终局，数子简化判胜。
  - 黑白棋：合法夹击翻转，无法落子自动跳过，双无手或满盘终局按子数判胜。
- **录像与回放**：行棋中记录完整步序，存档包含录像；`replay`/GUI 回放可逐步查看局面演变。
- **账号管理**：本地 `accounts.json` 保存用户、密码哈希和战绩（总场次/胜场）；支持登录/注册，游客可直接对局；AI 标记身份与等级；对局结束自动更新登录用户战绩，录像含玩家档案信息。
- **界面展示**：控制台和 GUI 均展示玩家用户名/身份与战绩，支持保存/读档/回放；棋盘可点击落子，AI 回合自动执行。

## 设计模式

- 工厂模式：`GameFactory` 创建不同游戏与棋盘。
- 策略模式：AI 等级与不同游戏规则的落子合法性。
- 命令模式：控制台命令封装为命令对象。
- 建造者模式：控制台 UI 组件组合。
- 模板方法：`Game` 基类定义行棋流程；子类覆盖胜负/平局规则与特殊动作（虚着）。
- 备忘录：历史记录+录像用于悔棋与回放。
